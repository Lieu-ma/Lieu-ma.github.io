Personal academic website for sharing research interests, selected project results, publications, professional background, and a public CV.

## Pages
- `index.html` — Home
- `research.html` — Forward learning, inverse recovery, and PDE dynamics exploration
- `cv.html` — Curriculum vitae

## GitHub Pages
Upload all files at the repository root, including `assets/` and `.nojekyll`. In your repository **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, and save. The repository must support GitHub Pages on your plan. For an account site, the repository name follows `<username>.github.io`.

The site is static and can also be previewed by opening `index.html` locally. No external JavaScript libraries or remote analytics are required.
